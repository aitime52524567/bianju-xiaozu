# 网剧编剧制作小组 · 协作工作台

一个可安装到手机主屏（PWA）、支持**团队云端共享同步**的编剧协作工具。
功能：成员管理、剧本库、分集大纲、人物小传、审核流程、工作流（自动流转）、公告与待办。

---

## 一、它现在是什么

- **网页应用（PWA）**：华为（安卓）和苹果（iOS）手机都能「添加到主屏幕」，像 App 一样全屏打开、有图标。
- **云端共享**：所有成员在各自手机上看到**同一份数据**，任何人的改动约 4 秒内同步到所有人。
- 数据存于服务器上的 `data.json`（已预置你的《风水设计师》项目）。

## 二、文件结构

```
编剧/
├── index.html            前端页面
├── css/style.css         样式

├── data.json             共享数据（团队数据）
└── README_部署.md        本文件
```

## 三、部署到公网（手机才能访问）

手机要访问，必须把项目部署到一个**公网 HTTPS 地址**。下面用免费的 Render 举例（最省事）。

### 方法 A：Render（推荐，免费）

1. 注册登录 https://render.com （可用 GitHub 账号）
2. 把本文件夹上传到一个 GitHub 仓库
3. Render 首页 → **New +** → **Web Service** → 连接你的仓库
4. 关键配置：
   - **Build Command**：留空
   - **Start Command**：`node server.js`
   - **Instance Type**：选 `Free`
5. 点 **Deploy**，等 1–2 分钟，拿到一个 `https://xxxx.onrender.com` 地址

> Render 免费实例闲置会休眠，首次打开可能等几十秒，属正常。

### 方法 B：其他平台

`server.js` 是零依赖的 Node 服务，任何支持 Node 的平台都能跑：
- **Railway**、**Fly.io**、**Vercel**（需配合数据库）等
- 或自己的服务器/云主机：安装 Node 后执行 `node server.js`

### 方法 C：本机临时测试

电脑上装好 [Node.js](https://nodejs.org) 后，在本文件夹运行：

```bash
node server.js
```

浏览器打开 `http://localhost:8080` 即可（仅本机能访问，手机连不上）。

## 四、手机安装成「App」

部署后，把公网地址发给团队成员，各自在手机上操作：

### 华为 / 安卓手机

1. 用浏览器（Chrome 或自带浏览器）打开你的公网地址
2. 等页面加载完，点浏览器右上角 **⋮ 菜单**
3. 选 **「添加到主屏幕」/「安装应用」**
4. 主屏出现「编剧小组」图标，点开即用

### 苹果 iPhone

1. 用 **Safari** 打开公网地址
2. 点底部 **分享按钮（↑）**
3. 选 **「添加到主屏幕」**
4. 主屏出现图标，点开即用（全屏、无地址栏）

## 五、使用要点

- 首次打开会自动从云端拉取团队数据。
- 任何成员的增删改，约 4 秒内同步到所有人（侧边栏底部会显示「☁️ 已连接云端同步」）。
- 工作流：`撰写 → 一审 → 二审 → 终审 → 定稿`，每步自动派任务给对应岗位的人。

## 六、当前限制（重要）

1. **无登录鉴权**：任何人拿到网址都能编辑，适合互相信任的小团队；若需账号登录，需再加一层身份认证。
2. **整份覆盖式同步**（last-write-wins）：多人**同时**编辑同一条数据时，后保存者覆盖前者；日常错开操作没问题。
3. **依赖设备时间**：同步用时间戳判断新旧，请让手机时间尽量准确。
4. iOS 主屏图标用的是 SVG，个别旧版 iOS 可能显示为截图；不影响使用。

---

## 七、常见问题

- **手机打不开网址**：确认部署地址是 `https://`，且服务器在运行。
- **数据没同步**：看侧边栏底部是否显示「☁️ 已连接云端同步」；单机模式（`file://` 打开）不会同步。
- **想重置数据**：删除服务器上的 `data.json` 重启即可（会回到初始状态）。
